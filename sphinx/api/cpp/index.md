# Overview

The C++ API is generated by Doxygen and Breathe from the headers of each
package, all at the same version as the Python API.

| Package | Content | Source |
| ------- | ------- | ------ |
| [hpp-util](hpp-util/index.md) | Logging, benchmark and quality assurance tools | [GitHub](https://github.com/humanoid-path-planner/hpp-util) |
| [hpp-statistics](hpp-statistics/index.md) | Statistics on motion planning algorithms | [GitHub](https://github.com/humanoid-path-planner/hpp-statistics) |
| [hpp-pinocchio](hpp-pinocchio/index.md) | Interface between pinocchio and hpp-core | [GitHub](https://github.com/humanoid-path-planner/hpp-pinocchio) |
| [hpp-constraints](hpp-constraints/index.md) | Nonlinear constraints | [GitHub](https://github.com/humanoid-path-planner/hpp-constraints) |
| [hpp-core](hpp-core/index.md) | Basic classes, path planning problems and solvers | [GitHub](https://github.com/humanoid-path-planner/hpp-core) |
| [hpp-manipulation](hpp-manipulation/index.md) | Manipulation planning | [GitHub](https://github.com/humanoid-path-planner/hpp-manipulation) |
| [hpp-manipulation-urdf](hpp-manipulation-urdf/index.md) | SRDF parser for manipulation planning (handles, grippers, contact surfaces) | [GitHub](https://github.com/humanoid-path-planner/hpp-manipulation-urdf) |

The dependencies have their own documentation:

| Package | Content | Documentation | Source |
| ------- | ------- | ------------- | ------ |
| coal | Collision detection and distance computation | [Doxygen](https://gepetto.github.io/doc/coal/doxygen-html/index.html) | [GitHub](https://github.com/coal-library/coal) |
| pinocchio | Kinematic chains with dynamic computations | [Doxygen](https://gepetto.github.io/doc/pinocchio/doxygen-html/index.html) | [GitHub](https://github.com/stack-of-tasks/pinocchio) |
